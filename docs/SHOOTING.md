# 宠物素材拍摄脚本（SHOOTING）

> 版本：v1.0　｜　日期：2026-08-14
> 本文档是 SPEC §4（素材采集规范）的**现场执行版**：把规范转成"准备什么 → 分几次拍 → 每次按什么顺序拍 → 什么叫合格"的可勾选脚本。打印或手机打开均可。
> 采集总原则（SPEC §4.6）：**抓拍优先，后期定起止**。不要引导宠物表演，长时段固定机位抓拍，后期从长素材中截取天然满足 `[锚定] → [动作] → [锚定]` 的片段。

---

## 0. 一表速览

| 项 | 要求 |
|---|---|
| 分几场拍 | 4 场（每场 10–20 分钟净拍摄，可跨多天） |
| 第 1 场目标 | **最小启动集**（坐/站/走/趴/睡 + 过渡），拍完即可运行 |
| 每场锁定 | 1–2 类动作，不贪多 |
| 机位 | 三脚架固定，**水平侧机位**，全程不动 |
| 背景 | 纯色布幕 + 每场开拍先录 1–2 秒空背景 |
| 画质 | 1080p 以上，30–60fps |
| 环境 | 安静（关风扇/空调/电视），保留原始音轨 |
| 禁忌 | 不镜像凑方向（花纹不对称宠物）、不让可见人手入镜（互动镜头穿背景色袖套） |

## 1. 拍摄前准备（一次性，约 30 分钟）

### 1.1 场地布置检查单

- [ ] **背景**：单一均匀纯色布幕（推荐中灰/中蓝），与宠物毛色反差明显；布面平整无褶皱、无杂物、无阳光直射造成的亮斑
- [ ] **台面**：拍摄台面即"地面"，平整、硬质（行走脚步声真实）、台面颜色与背景布接近或深色，宠物足部不悬空不出画
- [ ] **灯光**：两盏漫射灯（或窗户散射光）从正面/侧面补光；**背景布上无宠物影子**（宠物距背景 ≥ 1m 可有效避免）；宠物身上无过曝白块
- [ ] **机位**：三脚架固定在宠物**侧面**（镜头光轴与行走方向垂直）；高度与宠物肩高平齐；**量好机位距台面距离并记录**——后续所有场次必须同一距离（尺度统一的生命线）
- [ ] **画面构图**：宠物侧向站立时占画面高度约 1/2–2/3，左右各留出行走余量（行走段需要约 2–3 倍宠物体长的横向空间）
- [ ] **收音**：机顶/领口麦克风距宠物 1–2m；关风扇/空调/电视/窗户（街道噪声）
- [ ] **相机参数**：1080p 或 4K、30 或 60fps、锁定曝光与白平衡（**关闭自动曝光/自动白平衡**，避免拍摄中途亮度漂移破坏色键）

### 1.2 物料清单

- [ ] 背景布 + 固定夹 / 支架
- [ ] 三脚架 + 手机/相机
- [ ] 补光灯 ×2（可选，自然光均匀时可省）
- [ ] **背景色长袖/手套**（第 3 场互动镜头用，与背景布同色系）
- [ ] 宠物零食（场外引导视线用）、它喜欢的玩具（第 4 场）
- [ ] 食盆/水盆（第 4 场，颜色无所谓——道具允许入镜）
- [ ] 记录纸/手机备忘录：记机位距离、日期、场次

### 1.3 试拍自检（正式开拍前必做，2 分钟）

1. 录 10 秒：空背景 2 秒 + 宠物在台面走一遍
2. 回放检查：
   - [ ] 宠物**全身**（含尾巴尖、耳朵尖）全程在画面内
   - [ ] 背景颜色均匀，宠物靠近背景时背景上**没有影子**
   - [ ] 宠物毛色与背景可明显区分（纯白/纯黑宠物尤其要查）
   - [ ] 画面不抖、不糊，亮度全程稳定（无自动曝光呼吸）
3. 有问题就地调整（换背景色/补光/拉开宠物与背景距离），**宁可在这一步返工**——抠像质量是垃圾进垃圾出的源头

## 2. 通用拍摄纪律（每场都要遵守）

1. **先录空背景**：每场开拍、每次布光/机位有任何变动后，先录 1–2 秒**纯空背景**作色键参考帧
2. **抓拍优先**：宠物上台后开机连录 10–20 分钟，人退到镜头外或穿背景色袖套；用零食/玩具在**镜头外**引导它转换动作，后期截取合格段
3. **起止锚定意识**：合格片段 = 从锚定姿态开始、回锚定姿态结束。抓拍时心里盯住两个锚定：
   - **端坐**（主锚定）：正面、放松、面向镜头
   - **站立**（副锚定）：侧面、四肢着地静止
   宠物自然停驻在锚定姿态的瞬间，就是截取点——**停驻 ≥ 1 秒**的才好用
4. **方向成对**：花纹不对称的宠物，行走/转身必须左右两个方向都实拍（**禁止后期镜像**，斑纹翻边会破坏"就是它"）；对称宠物可只拍一侧
5. **人不入镜**：可见的人手/手臂会被抠像保留在成片里。互动镜头操作者必须穿背景色袖套，或改场外引导
6. **道具规则**：食盆/玩具可以入镜（这类片段走特殊过渡，SPEC §8.4），但**道具入镜后全程保持静止**，且该段不要试图接锚定中转
7. **安静**：人少说话、少走动；宠物实际发声（叫唤/哈欠声/进食声）的段落在归档时**特别标注**（入库时打 `embeddedAudio`，音画同步用）
8. **中途不动机位**：一场之内机位、焦距、曝光、白平衡全部锁定

## 3. 分场拍摄计划

> 每场净拍摄 10–20 分钟，宠物疲劳或烦躁就收工，改天再拍。场次之间没有紧迫顺序，但**第 1 场完成即可运行最小宠物**，优先级最高。

### 第 1 场：最小启动集（★ 最高优先）

**目标**：凑齐让宠物"活起来"的 6 段主体 + 过渡段。本场锁定基础生命动作，不拍互动。

| # | 镜头 | 方向 | 目标时长 | 起止锚定 | 合格标准 |
|---|---|---|---|---|---|
| 1 | 端坐 | 正面 | 3–5s × 2 条 | —（锚定本身） | 放松端坐、面向镜头、静止 ≥ 3 秒、无打哈欠/突然转头 |
| 2 | 站立 | 侧面 | 3–5s × 2 条 | —（锚定本身） | 四肢着地静止、侧面轮廓完整 |
| 3 | 行走 | **左行** | 5–8s × 2 条 | 站立→站立 | 起止各有 ≥1 秒站定；步伐自然匀速；全程侧身在画内 |
| 4 | 行走 | **右行** | 5–8s × 2 条 | 站立→站立 | 同上（对称宠物可只拍一侧，导入时标记对称） |
| 5 | 趴卧 | 任意 | 5–10s × 2 条 | 循环段 | 趴定后呼吸平稳、可找到 ≥3 秒首尾姿态一致的循环段 |
| 6 | 睡眠 | 任意 | 越长越好 | 循环段 | 真睡/深放松，含一次自然翻身更佳 |
| 7 | 起身过渡（坐→站） | 任意 | 1–3s × 2 条 | 端坐→站立 | 起止锚定各停 ≥1 秒 |
| 8 | 趴下过渡（坐→趴） | 任意 | 1–3s × 2 条 | 端坐→趴卧 | 同上 |

**抓拍技巧**：行走最难。把零食放在台面两端引诱往返走动，人退开连录；一次走动里起止自带站定的就是合格条。拍够 2 条/项即可收工（变体第 2 场再补）。

**本场收工核对**：[ ] 8 项每项 ≥ 1 条合格 → 即可导入运行（SPEC 附录 A 最小启动集）

### 第 2 场：转身 + 高频变体（反循环感）

**目标**：边缘转身能力 + 闲置状态变体，缓解循环感。

| # | 镜头 | 方向 | 数量 | 起止锚定 | 备注 |
|---|---|---|---|---|---|
| 1 | 转身 | **双向** | 各 1–2 条 | 站立→站立 | 到达"边界"自然掉头即可；不对称宠物必须双向实拍 |
| 2 | 端坐变体 | 正面 | 共 2–3 种 | — | 不同坐姿/视线方向各来一条 |
| 3 | 趴卧变体 | 任意 | 共 2 种 | 循环段 | 不同趴姿 |
| 4 | 睡眠变体 | 任意 | 1–2 条 | 循环段 | 翻身段单独留 |
| 5 | 稀有动作组 | 任意 | 有多少收多少 | 端坐 | **哈欠 / 伸懒腰 / 挠痒 / 抖耳 / 吐舌**——偶发插入用，拍到就是赚到；发声的标注音轨 |

**抓拍技巧**：稀有动作靠等。宠物困倦期（饭后/午后）开录趴着连录 15 分钟，哈欠懒腰自然出现。

### 第 3 场：互动响应（需背景色袖套）

**目标**：鼠标抚摸/点击/呼唤/拖拽的响应片段。**本场操作者全程穿背景色长袖+手套**（SPEC §4.7）。

| # | 镜头 | 拍法 | 起止锚定 | 合格标准 |
|---|---|---|---|---|
| 1 | 被抚摸享受 | 袖套手入镜抚摸头顶/背部 | 端坐→端坐 | 画面只保留宠物反应（眯眼/蹭）；袖套与背景同色、无强光反射 |
| 2 | 点击呼应（抬头看镜头） | **场外引导**：零食从镜头方向引诱抬头 | 端坐→端坐 | 抬头看镜头 ≥1 秒，无需人手入镜 |
| 3 | 被呼唤转身 | 镜头外呼唤，宠物闻声转头/转身 | 端坐→端坐 | 反应自然 |
| 4 | 被抱起/悬空 | 袖套手托起（实在无法避免手部可见也接受，SPEC §4.7 例外条款） | 任意 | 悬空挣扎/放松姿态 2–4 秒；预览确认观感可接受 |
| 5 | 松手落回 | 接 #4，放回台面 | →站立/端坐 | 落地站稳 |

**替代方案**：袖套方案观感违和时，全部改场外引导（§16 风险 7 的备选）——抚摸镜头可以只拍"宠物被摸时的反应"，手在画面外上方摸，只留宠物上半身。

### 第 4 场：个性招牌 + 情绪需求（身份灵魂）

**目标**：这只宠物独有的东西。前 3 场是"一只宠物"，本场是"**它**"。

| # | 镜头 | 说明 | 入库标签 |
|---|---|---|---|
| 1 | 招牌动作 ×N | 翻肚皮 / 叼玩具 / 打呼噜 / 怪睡姿 / 蹭人 / 冲刺跑酷……它独有的全部收 | `signature: true`，低频偶发 |
| 2 | 讨食 | 看到食物的兴奋/乞食姿态 | 情绪类 |
| 3 | 进食/喝水 | 食盆/水盆入镜（道具规则：道具入镜后静止） | `prop: true`；含咀嚼声的标 `embeddedAudio` |
| 4 | 求玩/无聊/开心/烦躁 | 有多少拍多少，丰富情绪层 | 情绪类 |
| 5 | 叫声专项 | 安静环境下逗它叫（叫唤/呼噜），**保留原始音轨** | `embeddedAudio: true` |

**抓拍技巧**：叼玩具类让玩具从画面外滚入；进食段食盆提前放好再让宠物上台，避免"人放盆"入镜。

## 4. 合格片段速查卡（现场自查 / 后期截取标准）

一段素材能入库，必须同时满足：

- [ ] **全身入画**：头、尾、四肢、耳朵全程不被画面边缘裁切
- [ ] **起止合规**：非循环段起于锚定、止于锚定，两端各停驻 ≥1 秒；循环段能找到首尾姿态一致的 loop 点
- [ ] **背景干净**：全程背景色均匀、无影子移位、无其他物体/人入镜（袖套/道具例外条款除外）
- [ ] **曝光稳定**：段内无亮度/白平衡漂移
- [ ] **焦点实**：毛发边缘清晰不糊（运动模糊严重的行走段报废重拍）
- [ ] **音轨保留**：即使画面静音段，原始音轨也不删（入库时分离使用）
- [ ] **时长合规**：普通段 3–10 秒，行走段 5–8 秒，过渡段 1–3 秒

**宁可多拍不要少拍**：同一动作多留 1–2 条备选，抠像/跟踪在导入时才知道哪条质量好。

## 5. 拍后整理与归档

### 5.1 文件命名（建议）

原始素材归档到独立文件夹（如 `D:\宠物素材\`），按场次分目录、按下式命名：

```
D:\宠物素材\
  2026-08-16_第1场_启动集\
    01_端坐_正面_A.mp4
    03_行走_左行_B.mp4
    07_过渡_坐转站_A.mp4
  2026-08-23_第2场_变体\
    ...
```

命名要点：`场次内编号_内容_方向_条次`；发声片段加后缀 `_有声`（如 `12_进食_有声_A.mp4`）提醒入库时打 `embeddedAudio`。

**原始长片保留**：连录的 10–20 分钟原始文件不要删，后期补拍时可能还能从中截出新片段。

### 5.2 入库对应

1. 打开应用托盘菜单 → **「导入片段…」**（清单引导式导入向导，SPEC §5.5）
2. 向导清单按 SPEC §4.4 分组，**最小启动集置顶**，缺项标红——对照本脚本第 3 场的核对表逐项导入
3. 每段流程：选视频 → 圈选背景参考色/帧（用每场开拍录的空背景）→ **抠像预览 + 边缘放大检查** → 裁剪/标 loop（行走段自动跟踪裁切 + 手动校正位移曲线关键点）→ 填标签（state/方向/锚定/signature/prop/embeddedAudio）→ 转码入库
4. 入库失败或预览边缘质量差 → 对照 §6 排查，必要时重拍（在世可补拍是本路线最大优势）

## 6. 常见问题排查

| 症状 | 原因 | 处理 |
|---|---|---|
| 抠像后宠物边缘一圈背景色 | 背景与毛色太近 / 容差过大 / 溢色 | 换反差更大的背景色重拍；补光减少背景阴影 |
| 半透明绒毛丢失、边缘锯齿 | 纯色键对绒毛的固有限制（SPEC §5.1 质量悬崖） | 提高拍摄分辨率（4K）、确保毛发焦点实；仍差则接受硬边缘风格或换毛色反差更大的背景 |
| 背景上有宠物影子 | 宠物离背景太近 / 硬光直射 | 宠物距背景 ≥1m；改漫射光、两侧补光 |
| 段内亮度忽明忽暗 | 相机自动曝光/自动白平衡 | 锁定曝光与白平衡重拍 |
| 导入后发现方向拍反了（花纹不对称） | 用了镜像 | 对称宠物可在 persona 标记对称直接镜像；不对称宠物必须重拍该方向 |
| 行走段宠物出画/忽大忽小 | 机位动了或宠物走斜线 | 检查三脚架固定；行走路径用零食引导成直线 |
| 抚摸镜头里有手 | 没穿袖套 | 穿背景色长袖重拍，或改场外引导方案（第 3 场替代方案） |
| 不知道还差什么 | — | 看导入向导清单：标红项 = 待补拍项（SPEC §5.5 兜底机制） |
